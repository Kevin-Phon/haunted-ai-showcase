See the [challenge](https://dev.to/challenges/hacktoberfest-week4-2026-10-26), [event rules](https://dev.to/page/hacktoberfest-week4-2026-10-26-contest-rules) and [general rules](https://dev.to/page/official-hackathon-rules). The owner approved this source snapshot for `Kevin-Phon/haunted-ai-showcase` and the [MIT license](../LICENSE) for rights the owner can grant. Public repository access and demo playback require separate verification. Actual contest submission remains subject to final owner authorization; this page is not a submission receipt.

## What an entry should explain

Use the official template and required `devchallenge` and `hf26challenge` tags at actual delivery. Explain what was built, show an accessible demo/video, link reviewer-accessible code, describe implementation and explain how local open-weight AI contributes. Include actual credits and candid limitations. Verify current rules and links before publishing.

The implementation connects a React interface, FastAPI rules, validated story JSON and a local Ollama/Qwen adapter. Generated output selects permitted character material; it does not invent authoritative evidence or judge the ending. The [architecture](architecture.md), [verification summary](progress.md) and [credits](../THIRD_PARTY_NOTICES.md) explain that distinction.
