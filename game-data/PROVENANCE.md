character knowledge, dialogue fallbacks, puzzle fragments, rules and guides were
developed with Codex assistance. The case and characters are fictional, not
historical quotations or archival records. No claim of exclusively human authorship,

The frontend's interface, atmospheric layers, state covers, puzzle controls and
other CSS/code presentation are project-authored with AI assistance. They are
separate from the generated raster artwork. The library drawer cover follows
accepted public object state; decorative machine illumination does not establish
calibration success. These effects do not control authoritative game outcomes.

## Original procedural sound

Both sounds were synthesized from sine functions by the project's
`apps/frontend/scripts/generate-audio.py`, without third-party samples or recordings.
The synthesis code was developed with Codex assistance.

| File | Actual delivered format |
| --- | --- |
| `media/manor-ambience-v1.wav` | 8 seconds, mono 16-bit PCM, 22050 Hz, 352844 bytes |
| `media/discovery-v1.wav` | 1.5 seconds, mono 16-bit PCM, 22050 Hz, 66194 bytes |

Audio is optional and begins off. Readable descriptions and transcripts retain
information. Discovery sound is presentation-only and uses a validated public
asset reference; neither audio playback nor animation completion grants progress.
